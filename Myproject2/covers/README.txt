REAL GAME COVER SETUP

The shelf selects the top seven CSV records per console. It tries exact artwork URLs and Libretro box-art filenames. No illustrated placeholder is shown. If a cover cannot be found, that case is hidden and the count shows fewer than seven.

To guarantee all seven for every console, obtain the correct game cover for each title/platform from an authorized source, save in covers/, and add an entry to coverFiles in sketch.js, e.g.
  'Wii Sports|Wii': 'covers/wii-sports-wii.jpg'

Cover image copyright is separate from metadata. Check source terms before republishing.
