ACTUAL GAME SOUND SETUP

No copyrighted game audio recordings are included. Private/class use does not automatically provide redistribution rights.

If you have an authorized clip for a game, put it in sounds/ and add its filename to the gameAudio object in sketch.js:
  'Wii Sports|Wii': 'sounds/wii-sports.wav'

The game case click will play the exact supplied clip. No substitute synthesized sound plays when a clip is missing.
